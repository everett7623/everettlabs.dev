## What it solves

Independent WordPress publications need a reading-first theme that keeps long titles, code,
documentation, and reference material clear without depending on a heavy page-builder stack.
Rackora for WordPress provides that structure as a block theme.

## Who it is for

Independent publishers, technical writers, documentation teams, and knowledge-base maintainers
running WordPress 6.6 or newer with full site editing.

## Why it exists

The Halo edition of Rackora already proved a quiet, low-image publishing layout. This WordPress
port keeps that editorial posture while using `theme.json`, block templates, patterns, and
server-rendered custom blocks instead of a classic PHP theme or page builder.

## Key capabilities

- Content-first homepage with profile card, categories, frequent tags, and sticky posts
- Post templates with table of contents, reading progress, heading anchors, code copying, and related reading
- Documentation template with a persistent outline and same-category navigation
- Archive timeline, category, tag, links, and about templates
- Light, dark, and system color modes with print styles and reduced-motion support
- Page-level SEO metadata and structured data that yield to installed SEO plugins when present

## Engineering notes

Rackora for WordPress is a GPL-3.0 block theme that targets WordPress `>= 6.6` and PHP `>= 7.4`.
The theme package is validated locally before release. The shared Rackora brand site is
[rackora.cc](https://rackora.cc); the Halo edition remains a separate approved project.
